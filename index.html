Orbit, un navigateur construit à deux

Depuis octobre 2026, projet personnel en binôme. Mon rôle : l'interface et le CSS.

Situation
Depuis octobre 2026, je développe avec un ami Orbit, un navigateur basé sur Gecko, le moteur de Firefox.
Tâche
Rendre l'interface calme et lisible : une barre latérale verticale et des espaces d'onglets reconnaissables au premier coup d'œil.
Action
  • Intégrer en CSS la barre latérale, les onglets épinglés en tuiles et les espaces colorés.
  • Animer en CSS le dégradé de la fenêtre quand on change d'espace.
  • Utiliser les icônes SVG de Lucide pour garder un style cohérent.
  • Tester chaque modification avec npm run dev, qui charge l'interface dans Firefox sans recompiler le navigateur.
  • Partager mon travail avec mon binôme sur GitHub.
Résultat
Orbit est publié en version 158.0.10 pour Windows et se met à jour automatiquement sur les postes où il est installé.

Dépôt GitHub d'Orbit

Ce portfolio, avec une veille qui se met à jour seule

Avril 2026, refait en octobre 2026. Projet personnel.

Situation
En avril 2026, pendant ma formation au CNAM, j'ai créé mon portfolio pour me présenter aux recruteurs.
Tâche
Afficher une veille technologique à jour sans modifier le site à la main.
Action
  • Intégrer la page en HTML et CSS sans framework, d'abord sur mobile.
  • Écrire un script Python qui récupère les dernières fuites de données et les dépôts GitHub en hausse.
  • Programmer GitHub Actions pour lancer ce script toutes les six heures et enregistrer le résultat.
  • Afficher les données en JavaScript à partir du fichier JSON.
  • Publier le site avec GitHub Pages.
Résultat
Le site est en ligne et la veille ci-dessous est mise à jour automatiquement plusieurs fois par jour.

Code source et historique des mises à jour
